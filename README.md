## Project structure

```
src/
├── app/                 Frontend
│   ├── (main)/          Every route: (auth) and (dashboard) groups, plus auth/confirm and share/[token]
│   ├── components/      UI kit (ui/), layout, tables, common, and per-feature components
│   ├── hooks/           Client hooks (useOrganization, useUrlState)
│   └── layout.tsx       Root layout
├── api/                 Server only: Supabase clients, session, queries, server actions, PDFs, messaging
├── types/               Types shared by app and api (database.ts is generated by `pnpm db:types`)
├── utils/               Shared helpers: calculation engine, validation schemas, formatting, routes
├── constants/           Shared constants: routes, cookies, permissions, page sizes, GST states
└── proxy.ts             Session refresh and route protection (must stay at src/)
```

Rules of thumb:

- Supabase is only queried from `src/api`. Files there that read data import `server-only`; mutations are Server Functions (`"use server"`) that client components may call.
- `types`, `utils` and `constants` never import from `app` or `api`, so both sides can use them.
- Route files in `app/(main)` stay thin: read params, call `api`, render a component from `app/components`.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
